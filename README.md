# 🍜 Hieu Bowl — Vietnamese Kitchen Landing Page

## 🌿 Overview

A modern Vietnamese kitchen landing page focused on fresh bowls, bold flavors, and a friendly dining experience.

The design combines expressive typography, vibrant food imagery, smooth animations, and a responsive editorial layout. ✨

## 🥢  Description

Hieu Bowl showcases Vietnamese rice bowls through a colorful and engaging restaurant website.
It maintains a consistent purple, light-blue, yellow, red, green, and white visual system. 🎨
Interactive motion, section navigation, hover states, carousels, and scrolling effects create a polished user experience. 💫
